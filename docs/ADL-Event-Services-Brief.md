# ADL Event Services — бриф для разработки сайта

## 1. Суть проекта

**Название:** ADL Event Services (рабочее название услуги — Event Support / Сервис сопровождения мероприятий)

**Позиционирование:**
> Вы занимаетесь бизнесом. Мы занимаемся организацией вашего пребывания.

**Что это:** сервис комплексного организационного сопровождения участников, экспонентов и делегаций деловых мероприятий в Казахстане (в первую очередь — Астана). Компания берёт на себя всё, что связано с логистикой приезда и пребывания, пока клиент занимается своими деловыми задачами на мероприятии.

**Первый целевой клиент / контекст:** Kazakhstan Machinery Fair (KMF) 2027, 31 марта — 2 апреля 2027, МВЦ EXPO, Астана. Дальше — любые другие мероприятия (Space Days, форумы, конгрессы, выставки, делегации).

**Ключевая идея бизнес-модели:** одна точка контакта (координатор) вместо того, чтобы клиент искал отдельно гостиницу, отдельно трансфер, отдельно доставку и т.д. Компания либо организует услугу сама, либо подключает профильного подрядчика.

**Услуги:**
- Размещение (отели, гостиничные блоки, VIP-размещение, групповые бронирования)
- Трансферы (аэропорт ↔ отель ↔ площадка, VIP-трансфер, автобусы/микроавтобусы)
- Визовая поддержка (приглашения, проверка документов, консультации, сопровождение процесса)
- Доставка документов и грузов (международная, в Астану, на площадку, срочная)
- Погрузочно-разгрузочные и транспортные работы (погрузка, разгрузка, перенос и упаковка оборудования, локальная транспортировка)
- Сопровождение официальных делегаций (встреча, переводчики при необходимости, индивидуальная программа, координация группы)
- Помощь в организационных вопросах / нестандартные задачи
- Персональный координатор мероприятия

**Важный тон коммуникации:** не обещать «решаем любые вопросы» (звучит несерьёзно). Формулировка: «Если вам нужна услуга, которой нет в списке — свяжитесь с нами. Мы постараемся организовать решение через нашу сеть партнёров.» Для визовой поддержки обязательно указывать: «Визовая поддержка не означает гарантированное получение визы — решение принимается компетентными государственными органами».

## 2. Структура сайта (карта страниц)

1. **Главная** (`/`) — позиционирование, анимированный hero (см. раздел 4), сетка услуг, блок кейсов/доверия, FAQ, контакты/карта
2. **Размещение** (`/accommodation`)
3. **Трансферы** (`/transfers`)
4. **Визовая поддержка** (`/visa-support`)
5. **Доставка** (`/delivery`)
6. **Грузовые и погрузочные работы** (`/logistics`)
7. **Комплексное сопровождение** (`/event-support`) — главная коммерческая страница, объясняющая модель «одна точка контакта»
8. **Для экспонентов** (`/for-exhibitors`) — до / во время / после выставки
9. **Для делегаций** (`/for-delegations`) — более премиальная подача
10. **Мероприятия** (`/events`) — страницы под конкретные события (KMF 2027, Space Days и будущие)
11. **Контакты** (`/contacts`) — большая форма заявки + карта + реквизиты
12. **Кейсы** — портфолио реализованных проектов с задачами и результатами
13. **Рекомендательные письма** — сканы отзывов и благодарностей от клиентов/партнёров

Каждая страница услуги строится по единому шаблону: H1 → подзаголовок → блоки услуг внутри направления → свой FAQ → CTA на форму заявки.

### Контент по каждой странице услуги

**Размещение** — H1: «Размещение участников и делегаций в Астане». Партнёры/варианты: Hilton, Wyndham и другие отели, групповые бронирования, VIP-размещение, гостиничные блоки. Суть: подбор и организация размещения с учётом дат, числа гостей, категории номеров, расположения относительно площадки.

**Трансферы** — H1: «Трансферы участников мероприятий в Астане». Варианты: аэропорт → отель, отель → EXPO, EXPO → отель, встреча делегаций, VIP-трансфер, автобусы, микроавтобусы, индивидуальные автомобили.

**Визовая поддержка** — H1: «Визовая поддержка участников мероприятий в Казахстане». Блоки: Приглашение / Документы / Консультация / Сопровождение. Обязательная оговорка про решение госорганов (см. выше).

**Доставка** — H1: «Доставка документов и грузов для участников мероприятий». Блоки: Международная доставка / Доставка в Астану / Доставка на выставку / Срочная доставка.

**Логистика/погрузка** — H1: «Погрузочно-разгрузочные и транспортные услуги». Перечень: погрузка, разгрузка, перенос оборудования, перемещение выставочных материалов, доставка до площадки / со стенда, упаковка, помощь при демонтаже, локальная транспортировка.

**Комплексное сопровождение** — H1: «Комплексное сопровождение участников мероприятий». Посыл: «Не знаете, к кому обратиться по организационному вопросу? Обратитесь к нам». Перечень того, что можно организовать: проживание, трансфер, визовую поддержку, доставку, транспортировку, погрузочные работы, документы, сопровождение делегаций, VIP-сервис. Блок «Одна точка контакта для решения организационных вопросов» — объясняет бизнес-модель.

**Для экспонентов** — H1: «Сервис для экспонентов». Структура по фазам: До выставки (приглашение сотрудников, виза, гостиницы, трансферы, доставка оборудования/образцов, логистика) → Во время выставки (трансферы, доставка, погрузочные работы, перемещение оборудования, срочная помощь) → После выставки (вывоз оборудования, обратная доставка, документы, трансфер в аэропорт).

**Для делегаций** — H1: «Сопровождение иностранных делегаций в Казахстане». Премиальный список: размещение, виза, встреча в аэропорту, транспорт, переводчики при необходимости, сопровождение, деловые поездки, индивидуальная программа, координация группы.

**Контакты** — форма «Расскажите, что вам необходимо — мы организуем решение»: Компания / Страна / Мероприятие / Дата приезда / Количество человек / чекбоксы услуг (Отель, Трансфер, Виза/приглашение, Доставка, Грузчики, Транспортировка оборудования, Другое) / Комментарий / WhatsApp или Telegram / кнопка «Отправить запрос».

## 3. Концепция анимации главной страницы (hero)

**Референс:** https://jeskojets.com/ — сайт чартера частных джетов, где на первом экране закрытый иллюминатор самолёта, который открывается шторкой автоматически при загрузке страницы, без клика пользователя.

**Идея для ADL Event Services** — цепочка коротких «эпизодов», передающих путь клиента от прилёта до завершения пребывания, привязанная к скроллу:

1. **Загрузка сайта** — закрытый иллюминатор самолёта (шторка закрыта). Без каких-либо действий пользователя, автоматически, с задержкой ~0.5 сек, шторка иллюминатора открывается.
2. **После открытия** — в иллюминаторе видно небо и плывущие облака (лёгкая фоновая анимация движения облаков, ничего не нажимая). Поверх — текст о позиционировании/услугах.
3. **Любой скролл (даже минимальный)** должен переключать сцену на следующий «эпизод» — то есть логика «один скролл = один переход», а не плавная параллакс-прокрутка одной сцены. По сути — полноэкранный scroll-hijacking со сценами-слайдами, внутри каждой сцены могут быть свои лёгкие анимации (облака, движение).
4. **Эпизод 2 — аэропорт:** переход из иллюминатора в зал прилёта международных рейсов, где клиента встречают (например, табличка/встречающий).
5. **Переход-зум:** клиент берёт чемодан — камера/кадр зумируется на чемодан как переходный элемент к следующей сцене.
6. **Эпизод 3 — трансфер:** клиент садится в машину, дверь закрывается (зум на деталь как переход).
7. **Эпизод 4 — гостиница/размещение:** машина прибывает, следующий кадр — гостиница.
8. Далее по той же логике могут быть добавлены сцены по остальным услугам (сопровождение на мероприятии, туристическая часть, проводы в аэропорт) — точный набор сцен = количество ключевых этапов услуги.

**Характер переходов:** быстрые, резкие (не плавный медленный параллакс), но при этом смысловая цепочка «услуга за услугой» должна считываться понятно. Общее ощущение — солидно, аккуратно, не перегружено.

**Каждая сцена/блок услуги:**
- имеет свой анимационный фон (тот самый эпизод: иллюминатор / аэропорт / трансфер / гостиница и т.д.)
- поверх — заголовок и текст об этой услуге
- кнопка «Подробнее» — по клику уводит на обычную статичную страницу этой услуги (без анимации), с блоками, прайсами и контактами — это как раз те страницы услуг, что описаны в разделе 2.

**Инструмент анимации:** пользователь готовит анимационные сцены в **Tumult Hype** (экспортирует как HTML/CSS/JS-сцены), которые затем нужно интегрировать в сайт как блоки/секции.

### Технические рекомендации по реализации

- **GSAP + ScrollTrigger** — основной инструмент для логики «скролл = переход между сценами» (scroll-hijacking, snap между секциями, привязка анимации к прогрессу скролла).
- **Lenis** — плавный скролл поверх обычного, хорошо сочетается с GSAP.
- Экспортированные из Hype сцены можно подключать как отдельные HTML/CSS/JS-фрагменты внутри общей структуры секций, управляемых GSAP ScrollTrigger (Hype даёт покадровую/таймлайн-анимацию, ScrollTrigger — привязку этой анимации/переключения сцен к скроллу).
- Обязательно учитывать `prefers-reduced-motion` и производительность (много тяжёлых анимаций подряд может тормозить на слабых устройствах/мобильных — предусмотреть облегчённую версию сцен для мобильных).
- Итоговая логика: hero-секция с покадровыми сценами (иллюминатор → аэропорт → трансфер → гостиница → ...) → при клике «Подробнее» на любой сцене — переход на обычную статическую страницу соответствующей услуги без анимаций.

## 4. Дополнительные блоки (рекомендации по улучшению)

- В форме заявки — обещание скорости ответа («отвечаем в течение 30 минут»), плавающая кнопка WhatsApp/Telegram, переключатель языка RU/EN/KZ, загрузка файла (список участников, ТЗ на груз).
- Блок «Как мы работаем» (заявка → координатор → решение).
- Тизер стоимости на страницах услуг («от X ₸» / «зависит от количества человек»), даже без точных цифр.
- Статистика доверия (число мероприятий/делегаций), если есть реальные цифры.

## 5. Технологический стек и деплой (общая часть проекта)

- Статический сайт (HTML/CSS/JS) или на выбранном фреймворке, анимации — GSAP + ScrollTrigger + Lenis.
- Репозиторий — GitHub.
- Деплой — GitHub Pages (просто, бесплатно, для статики) либо Vercel/Netlify (удобные превью на каждый пуш, кастомный домен).
- Админ-доступ к репозиторию — через Settings → Collaborators на GitHub (роль Write/Admin), отдельно от доступа к хостинг-панели (Vercel/Netlify dashboard).
